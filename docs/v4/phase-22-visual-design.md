# Phase 22 — Original Character Art & Visual Design

日期：2026-11-09  
目标：从“可见的 LPC 地图小人”推进到“可凝视的原创分层半身像”。不复制 Degrees of Lewdity 资产；借鉴分层人物组织方式，使用原创 SVG 图层。

## 1. 为什么不是继续放大 LPC

Phase 21 修好了 `.portrait` 的 2px flex bug，但 64×64 LPC 地图小人在 260px 舞台里仍然：

- 身体比例像地图单位，不像近景人物；
- 面部只有两个黑点，缺少眼睛、眉、鼻、嘴、表情；
- 服装/职业变化少；
- 放大后透明边距多，人物在框里偏小；
- 无法承载“这个人是谁”的情感连接。

Phase 22 新增 `apps/web/src/OriginalPortrait.tsx`：200×240 SVG 半身像，所有图层由代码/原创路径绘制，不依赖 LPC 贴图。

## 2. 图层

| 层 | 内容 |
|---|---|
| 背景 | 柔光圆环、暗角、肩部阴影 |
| 身体 | 肩/胸/衣领/纽扣/衣褶 |
| 头部 | 头型、耳、颈、下颌、肤色渐变 |
| 头发 | 后发、前发、刘海、鬓角、高光、老年灰发、婴儿软帽 |
| 面部 | 眼白、虹膜、瞳孔、高光、眼睑、眉、鼻影、嘴、脸颊、皱纹 |
| 服装 | 普通上衣、外套、翻领、领结、围裙、围巾、军装肩章、学生背带 |
| 配件 | 眼镜、耳环、职业徽章、fame 金别针、scandal 暗围巾、grief 黑臂章、debt 补丁、curse 红线 |
| 状态 | 死亡灰度、疾病低饱和、情绪表情、老年纹理 |

## 3. 年龄阶段

- **婴儿 0–2**：大头、圆脸、软帽、极小肩部；不画成人头发。
- **幼儿 2–5**：大头、短身体、圆眼、简单衣领。
- **儿童 6–12**：较大头身、校服/背带、短发型。
- **少年 13–17**：接近成人比例、瘦肩、学生装。
- **成年 18–64**：标准半身像；职业服装、发型、耳环、眼镜。
- **老年 65+**：灰发、皱纹、下颌线、深色披肩/外套。

## 4. 自动外观

输入：`appearance.skin/hair/clothes`、`appearance.doll`、`age`、`sex`、`occupation`、`roles`、`health`、`mood`、`stateTags`、`flags`、`died`。

规则：

- 肤色/发色/衣服颜色来自 palette；显式 doll 颜色优先。
- 医生/官员/作家/教授 → 深色外套 + 领结 + 眼镜。
- 学生 → 背带 + 眼镜。
- 士兵 → 军装肩章。
- 艺术家 → 围巾。
- 工人 → 围裙。
- fame → 金色别针。
- public-scandal → 暗色围巾。
- grief → 黑臂章。
- chronic-illness → 低饱和/病容。
- debt-bondage → 肩部补丁。
- cursed-by-wish → 红线。
- mood > 0.22 → 微笑；< -0.22 → 悲伤；< -0.55 → 愤怒；health < 0.32 → 病容。
- death → 灰度 + 暗角。

这套系统只服务观察，不增加装备管理。

## 5. 渲染与性能

- 纯 SVG，无图片加载失败；每个实例用 `useId` 生成唯一渐变 ID。
- 200×240 viewBox；肖像舞台显示 210×252；出生预览 92×110。
- 无外部请求，无 Canvas 像素读取，无 LPC 依赖。
- 保留 LPC `PaperDoll` 作为旧资产/fallback；`PersonPane` 与出生预览使用 `OriginalPortrait`。

## 7. 限制

- 这是原创 SVG 半身像，不是 DoL 级像素资产；面部/服装细节仍有限。
- 没有行走动画/姿态库；只有半身静态表情。
- 没有完整 wardrobe 编辑器；自动外观是规则叠加。
- 没有把每个历史人物做成独特手绘肖像；仍是程序化组合。
- 没有像素级 dithering/统一像素密度；后续可把 SVG 规格转为 PNG sprite sheet。
- 没有逐年历史服装数据库；1912–1955 的服装差异主要靠职业/年龄/状态。

## 8. 后续资产规范

如果继续扩充：

1. 先锁定 200×240 半身像比例、3–5 种头型、8–12 种发型、6–8 套时代服装。
2. 每个图层单独 SVG/PNG，透明背景，统一调色板与轮廓。
3. 每个年龄阶段做 3 个表情（neutral/happy/sad），再扩展 anger/sick。
4. 服装按 `era × class × occupation` 组织；特殊 State 只做配件/色调，不重画全身。
5. 用浏览器截图做视觉验收，不用“图层数量”冒充质量。
