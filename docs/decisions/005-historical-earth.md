# ADR 005 — 1900 年历史输入与开放人生

用户指定从 1900 年开始，允许此后任意时刻创建普通人物并参与历史、成为受害者。新纪元默认 earth-1900；旧世界归档，不将其 2020 年的既有记录倒写为 1900 年。

历史输入是经审核、带日期精度、来源、地域和有限参数的声明。输入按模拟器时钟激活持续过程；区域经济、供应、疾病、伤亡、守恒迁移以及个人遭遇来自实际状态推进。源事件与模拟后果分别标记，人物的出生、到达和参与月份不能倒推虚构。世界后续自主变化与史实输入可以分歧；模拟过程窗口结束不等于宣称现实战争结束。

扩大地名覆盖采用 Natural Earth 1:10m 城镇，保留旧 ID；以现代地区索引承载 1900 人口估计。没有选择声称完整历史疆界，因为尚无逐年边界/政体数据与对应继承迁移机制。该限制在 UI 与交付报告中明示。

不通过改写历史人口曲线强行控制模拟。战争和救助都消耗实际资源，具名人物受害规则不读取 ownerId。新增人生的职业按时代规范化，避免 1900 年直接出现现代程序员或航空网络。
