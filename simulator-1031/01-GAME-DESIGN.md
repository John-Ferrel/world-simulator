# 世界人生 / Another History — 游戏策划案 v1.0

**性质：** 游戏设计（Game Design）与内容设计。另见 `02-ENGINE-ARCHITECTURE.md` 的执行契约、`03-RESEARCH-AND-DELIVERY.md` 的证据与实施策略。

**设计基线：** 2026-10-31。此文是拟议的完整产品设计，不宣称当前 Codex 仓库已实现。文中安娜、约瑟夫等故事和数据均是**构造的游戏案例**，不是史实或运行截图。

## 0. 一句话、玩家到底在做什么

1900 年的真实地球，历史尚未确定。玩家创造一个**新生儿**：名字、性别、身体状态、外貌以及自由形式的祝愿。LLM 根据**此时真正的世界状态**深度编译出生契约及隐藏的可能人生。之后玩家基本不控制他。孩子在家庭、邻里、学校、职业、战争、疾病、婚姻、政治运动中自主生活，与其他玩家孩子、真实历史人物和普通 NPC 产生真实且持续的关系。有人早夭，有人平凡，有人建立企业、组织革命、改变战争或历史；死亡后留下真实人生档案与祝愿对照。

**三件中心玩法：** `人生模拟`、`小人之间的真实交互`、`个人与历史相互改变`。界面保持左人物—中日志—右地图的极简观察器。

**重要界限：** 这不是「角色成长游戏」（不指挥、不刷属性）；不是「互动小说」（历史共享且有状态守恒）；不是「LLM 对话酒馆」（不能靠说话直接决定结果）；也不是把地球大地图作为主要玩法的传统大战略游戏。

## 1. 已经确认的产品决策

| 决策 | 正式取值 | 后果 |
|---|---|---|
| 内容中心 | Person | 世界应首先体现在人的具体遭遇、共同生活及记忆里 |
| 角色入口 | 出生而非凭空出现成年人 | 孩子进入现存家庭、社区与人口账本 |
| 创建自由度 | 可编辑名字、性别、身体/外貌、自由祝愿 | 祝愿可为期望、异能、私有系统、禁忌或矛盾愿望，须深度解释 |
| 人物自主 | Radical | 出生设定不是永远不变的人格契约；没有主角保护 |
| 世界残酷性 | Harsh | 保留真实的婴儿死亡、战事、饥荒、伤病、屠杀与政治压迫；不是追求随机惨剧 |
| 历史起点 | 1900 年真实地球 | 地理、国家、人口、社会制度、历史人物以可追溯资料建立基线 |
| 历史偏离 | 真实 IF | 模拟发生后不强制跟随历史教科书；史实只作基线与吸引趋势 |
| 超常能力 | 少量真实异常个体 | 稀有、代价、范围、被社会发现的影响均是真实机制 |
| 新事件 | LLM 自动编译、自动入库 | 无须人工审核事件内容；编译失败的内容不进入生产 |
| 历史导演 | 强权限 | 可创造宏观冲击、历史人物相遇机会及结构性回归压力；行为必须留下干预账本 |
| 规模 | 10k+ 玩家注册/人物、另有至少 10k+ 具名背景人物 | 永久身份、较低频调度、聚合人口与持续社会网络 |
| 测试时间 | 30–60 秒/模拟年，可离线最大速率计算 | **缩人口不删系统**；正式世界速度作为可调整策略，不硬编码 |

## 2. 一个玩家进入游戏时看见什么

### 出生界面，不是角色构筑面板

示意（自由文本为核心）：

- `姓名`：埃莉诺·鲍尔（可自由输入，校验长度、违规输入，不强制历史常见名）。
- `性别与身体`：身体描述自由，结构化为出生性征、先天状况、感官与健康风险；不因“特殊”自动等于更强或更弱。
- `外观`：像素纸娃娃最初的外观，衣服与成长状态由世界改变。
- `祝愿`：「愿她听出一个人是否故意说谎；可她每次使用能力都会失去一段自己珍视的记忆。」

出生地、年份由**当前世界时间与可用出生家庭**决定；可以提供有限地区偏好，但不能凭空夺走活人的身份、头衔或财产。LLM 在后台解释祝愿，生成出生契约：原文、歧义解析、能力机制、限制、代价、表现形式、隐藏人生机会、出生所在家庭上下文。对人物的能力**保留原文与编译版本**，允许未来世界机制丰富后对不完整的愿望有新的解释，但不能暗改已使用的能力历史。

在正式提交前可以改出生信息与祝愿；提交出生事件之后不允许反向编辑曾经的出生事实。后续想法通过新生命或世界中的现实变化实现。

### 主游戏：极简，但信息真的存在

- **左侧：** 逐年龄变化的像素人物、衣着、职业、肢体伤残、婚姻或军职等少量高信息密度状态；不需要复杂人物管理表。
- **中间：** 按人的经历排列的时间线：普通生活、人物相遇、失败、记忆、社会与战争影响。事件可预览参与者和前因。没有真实后果的“今天又努力工作了”不应刷屏。
- **右侧：** 世界地图、人物在何地、地区与战争/经济/迁徙的变化。地图是解释人生，不是另一款策略游戏。
- **历史回放：** 世界只有一个当前时间；玩家可以停在自己的阅读进度，从出生开始看已发生的一生，不能改变共享过去。
- **死亡：** 不是游戏失败提示。展示生平、未完成之事、真实改变的人和组织、后代及出生祝愿对照。用户可继续观察后代或出生一个新孩子（具体账户额度由运营规则约束）。

## 3. 使「人生」变得具体的基础机制

### 3.1 一个人不是一包属性，而是参与中的生活

除了年龄、健康与性格，人物需要以下**可指向实际对象**的关系：

- **家庭**：谁共同生活、谁抚养、食物与租金谁承担、遗产与债务归属；婴幼儿不会独立找工作或参加政治活动。
- **教育**：就读的具体学校、科目、教师、资格、学费、考试、推荐；按时空制度决定可及性，不是 `education+1`。
- **职业**：雇佣合同的对象、职位、工资、工时、工作风险、工作场所、同事；无工作也不是简单的负数标签。
- **健康**：身体部位、疾病进展、治疗机会、成本、长期失能、照护；死亡率由年龄和当前环境风险决定，不能让两套系统重复杀人。
- **婚姻、亲子与亲密关系**：两个当事人有各自意愿和理解，社会制度约束婚姻可行性，孩子需要真实监护与人口结算。
- **政治、宗教、文化与阶层**：身份、组织成员、承担的义务、可参与的活动、受到的限制；不是 `ideology = liberal` 一个标签。
- **长期事务**：申请学校、寻职、追求某人、抚养孩子、申请赔偿、迁居、竞选、组织罢工、军事晋升；有参与方、进度、截止日、对手、条件变化与可中断性。

### 3.2 例子：父亲受伤，女儿是不是一定辍学？

游戏状态（**构造案例**）：1912 年，维也纳，印刷工 Josef 有雇主、班次、工资和家庭账本；其 12 岁女儿 Anna 在某所学校，有一名授课教师。

1. **工作事故**发生，来自工作地点的真实风险事件；伤害更新劳动能力，不直接修改女儿教育状态。
2. **雇佣结算**：原雇佣岗位无法继续，工资实际中断；伤病治疗需要真实支出。
3. **雇佣争议**：Josef 可以提出索赔；企业可以答复、和解或拒绝；在当地制度允许时可有法院、工会或保险参与。
4. **家庭账本**：储蓄、母亲收入、房租、家庭开支、赔偿和借贷共同决定实际收支缺口。
5. **教育连续性**：女孩会不会离校，取决于家人决定、学校制度、费用、她本人的意愿和已经存在的教师/亲属关系。
6. **共同世界后果**：同一工厂的另一名玩家人物如果知道这场事故，可能参与作证、组织互助或与 Josef 结怨。这些关系继续存在。
7. **历史路径**：工会可能利用多起真实案件形成政治议题，经过招募、谈判、选举或抗议推动制度改革，改革改变此后所有人的工伤索赔途径。

不是「父亲工伤 → 女儿辍学 → 激进+5」；每个转折都由**真实对象及未完成事务**组成。普通人生可以在任一步结束；不存在强行给每人安排英雄成长剧情。

### 3.3 人物之间的交互不能靠全局随机配对

相遇基础是**共处、社会纽带与现实事务**：家人/亲戚、学校班级、同事、邻里、军队单位、工会、咖啡馆、医院、迁徙旅途、会议、婚礼。

人物 A 向人物 B 发出请求时，先创建 PendingInteraction（邀请/求助/求婚/雇佣/借贷/告密/谈判）；B 有自己的可见信息与动机，可以答应、拒绝、拖延、欺骗、转告第三人或提出条件。系统不在 A 提交请求的同时强行写入 B 已经同意。

共同经历与认知必须有方向性：A 信任 B，不等于 B 信任 A；A 知道秘密，B 不一定知道。一个人物可能记错、误会或遗忘某段经历。日志不得把角色的**信念**当成客观事实。

### 3.4 一个组织拥有行动能力，不是成员列表

学校能够招生并颁发资格；企业能够雇佣、生产、借贷；工会有会费、成员、负责人、代表机制；军队有兵源、装备、补给和命令链；国家有法律、税、政权与强制权。

国家/组织的行动来源于职务权限、内部决策和可支配资源。一名玩家人物可以因进入某职位而影响 10 万人，但其影响必须通过具体机构执行，不能靠一个 `influence=100` 属性直接改写国家。

## 4. 宏观历史怎样真正落到每一个人身上

### 一套人口账，而不是两套并行游戏

全部人口按地区、年龄群、职业、家庭结构、社会身份等进行**聚合建模**；玩家人物、重要 NPC、历史人物是从中展开的具名个体，拥有持久身份和独立社会记录。

宏观人口中的士兵被具名后，原群体人数必须减少一人；战争中这名士兵伤亡时，宏观汇总不能再将他死亡一次。一个具名工人的工资不能在个体和宏观企业账上支出两次。

### 战争必须是真实的因果网络

战争由政治/军事组织的项目、联盟、补给、军队和地区控制结算；影响兵员征召、城市粮食、工作岗位、学校、交通、疾病、难民、家庭收入、家庭成员的去留与政治态度。具名人物能够通过职务、资源、情报、组织或技术干预战争过程。重大历史事件（战争、革命、金融危机）不是给每个角色各抽一次「受影响」卡片。

真实 20 世纪的暴行、迫害和战争伤亡可成为世界风险和历史事实，并保持史实/架空史明确区分；无需追求血腥文字或把任何民族/群体预设为天然有罪。

## 5. 1900 年真实地球与历史人物

- **1900 开局档案：** 国家、边界、主要聚落、政治制度、人口及社会阶层、经济结构、交通、技术、已有战争、具名历史人物；每项基于史料/数据，并记录来源与确定性等级。
- **真实资料的身份：** 1900 年以前的既成历史属于 baseline；1900 年以后的史实是候选历史参考，不是强制必须发生的事件。比如某个重要人物出生需要其父母仍然活着且出生条件可成立；历史可偏离。
- **历史人物的精度：** 常出场且具有真实影响的人使用完整模拟；大量历史名录先做索引与生涯时间窗，只有与现行世界相容时激活。不能把 28k 目录等同于 28k 个活跃智能体。
- **历史人物相遇：** 同一时间窗、能够合理到达的真实地点、共同社会网络或活动是条件。History Director 可以主动安排邀请、旅行、聚会和偶遇机会，但不得跨越物理条件凭空把已死者拖进酒馆。
- **历史回归：** 允许强 History Director 主动提出外交危机、经济冲击、社会运动、人物聚会等事件，创造历史轨迹重新接近现实的机会；但事后必须由人口、制度、组织和人物行为产生后果。干预来源必须可追溯。

## 6. 超常祝愿是社会史的一部分，不是额外小游戏

玩家愿望可能是普通期待、诅咒、超常能力或“自带系统”。出生时 LLM 深度理解其**语义**、可观察表现、限制、适用对象、消耗、失败条件、成长可能、公共后果和社会可见性。原文永久保存。

示例：「能识破故意谎言，但每次会失去一段珍贵记忆。」

- **真相：** 引擎记录事实、说话者主观相信什么、说出的命题、故意误导意图以及是否可感知；诚实的错误不等于撒谎。
- **发动：** 有具体对话及命题，能力符合观察距离/条件；从合法可用的记忆中选择代价对象并记录遗忘，不凭空删去世界事实。
- **效果：** 角色获得“该人这句话是故意欺骗”的个人知识，不必直接获得全部客观事实；其他角色并不自动得知。
- **历史影响：** 能力可能改变家庭关系、求职、情报工作和政治谈判，进而引发真实的制度和战争后果。

超常能力稀少的含义是**世界中实际拥有可超越现实规律效果的人数稀少**，并非每人都必然实现愿望；如果大量用户提出神级能力，由出生编译解释为潜能、成本很高的受限能力、普通期望或需时代条件激活的异常，而非为了“平衡”偷偷将愿望改成另一个东西。玩家能够在出生前看到可理解的编译摘要；隐藏的是未来人生，不是欺骗性改写祝愿。

## 7. AI 设计：让 LLM 创造机制与潜力，不拿它当随机日志润色器

### 7.1 出生：深度推演但不预定命运

在出生时读取该年份/地区的可验证事实、家庭和父母、社会政策、时代科技、孩子条件及祝愿。LLM 多角度生成**若干可能人生假设**，识别角色潜能、内在冲突、长期动机和可能遇到的障碍，将其编译为可执行条件规则、个人策略与可用能力。隐藏预演不直接写进世界时间表，也不提供给用户剧透。

某个角色可能希望成为医生，但从未就读学校；另一个人可能通过战争成为护士、政治活动家甚至死亡。出生时没有人可以提前决定这件事。

### 7.2 运行期：三类调用，不是人均固定调用

**创作调用**：世界出现全新技术、制度、社会冲突或内容缺口时，生成可复用的事件族/职业/组织行为，并自动编译发布。

**重规划调用**：人物目标破产、人格遭受重大转变或面对特殊复杂互动时，修订未来行为策略，不追溯修改过去。优先级不能只看权力和知名度，普通玩家人物也有预算与公平性保障。

**强导演调用**：主动塑造历史机会与外部冲击，改变当前可执行的社会环境。干预是新增事实、规则或事件来源，不是直接覆写已有事实。

普通行为、社会接触、疾病过程、出生死亡、经济交换和日志默认都由代码执行；死亡后可调用一次 LLM 根据真实生平总结，不得编造经历。

### 7.3 大规模 LLM 内容工厂：内容单位是机制族，不是句子

开发期批量建立**相互连接的内容族**（例如疾病治疗、学徒制、家庭债务、移民、战争征召、政治秘密、劳工运动、恋爱与婚姻、灾难救助、殖民/民族冲突、跨代遗产）。每族包含状态入口、参与角色、行为、相反回应、机构/资源条件、长期进程、失败和延迟后果、历史年代约束与可复用规则。

LLM 输出后进行格式编译、引用绑定、资源守恒、安全与效果检查、年代/区域检查、规则重复检测、合法状态迁移测试。正式世界的事件允许在**全部自动审核通过后无人工确认上线**。新规则注册后给未来事件使用；过去已发生事件仍按当时版本解释。

### 7.4 用户可见日志

只渲染**事实**，并区分传闻和角色的错误认知。普通经历使用内容模板，关键事件可有多角色对白/叙述片段，但不必须靠 LLM 为每件事写散文。重要的是同一件事可由多位当事人的不同认知与利益看到不同侧面，且都能追溯到同一条权威事件。

## 8. 如何自然地产生内容密度

必须由**社会活动场所**带来接触机会。七千多座城市中的 20k 具名人物即使分布不均，也不能只靠同城随机配对。世界还包含聚合普通人口；学校、工厂、军营、社区、教会、港口、医院、政府机构根据本地人口与需求生成可重复使用的社会结构。在需要时从人口单元激活有稳定身份的 NPC；一旦与具名人物形成重要关系便永久保留，而不是每次互动重新制造朋友。

有些人物的一生只有一段婚姻、几个亲密朋友和一份长工；这种生活仍应有明确的家庭、经济、疾病和社会历史，而不是靠导演强行让每个角色经历三次谋杀与两场革命。

## 9. 玩法内容覆盖矩阵（不是机械刷数量）

| 领域 | 必须具备的实际模拟互动 | 必须关联的宏观机制 |
|---|---|---|
| 婴幼儿 | 监护、营养、疾病、失亲、收养、家庭资源分配 | 人口、医疗、社会救济 |
| 少年 | 学校、师生、同伴、学徒、家庭劳动、教育限制 | 教育制度、阶层、地区经济 |
| 成年 | 雇佣、晋升、失业、创业、爱情、婚姻、育儿 | 产业、组织、财产和法律 |
| 老年 | 健康恶化、照护、退休、继承、遗言与关系终结 | 人口、养老制度、家庭财富 |
| 社会交往 | 介绍、邀请、请求、承诺、合作、误解、欺骗与背叛 | 地域、传播、机构、信息 |
| 政治 | 加入组织、招募、筹款、竞选、镇压、谈判、政变 | 政权、法制、税收、国界 |
| 军事 | 征召、服役、战伤、逃亡、情报、补给、复员 | 国家战争、工业、人口 |
| 历史与科技 | 发现、实验、机构采纳、制度阻力、社会扩散 | 技术、贸易、生产与文化 |
| 异常能力 | 条件发动、代价、泄露、被利用或被追捕 | 信息、宗教、政治、军事 |

**内容审计的单位是「可触发的机制组合与新后果」**，不是 `event_count`。事件定义 10,000 条也可能只有 30 条真能触发；反之 200 个机制族可以组合出大量各不相同的人生。

## 10. 例子：三条相交而非按剧本播放的命运

（完全构造的用于设计评审的例子）

- 玩家 A：1900 年出生在维也纳的 Anna，听谎但失忆。父亲工伤后她可能被迫中断学校；也可能通过老师获得资助。关键不是哪条情节更好，而是**母亲收入、校方制度、教师存在、个人性格和愿望代价**真的参与了结果。
- 玩家 B：1902 年在另一城市出生的 Karl，后来进入司法机构。他可以被指派处理工伤纠纷，和 Anna 的家庭或工会形成跨年关系。若 Karl 早亡或换职，整个链条可转向另一位具名人员，不要把他拉回固定剧情。
- 历史人物 C：某一真实人物在当时的城市和政治圈内活动；导演可以有意组织一次讲座、聚会、偶遇以创造联系。当代史实不保证其一定参加，也不保证人物随后必然完成历史教科书的行动。

如果 Anna 所在的工会在法律改革中发挥了作用，未来很多普通居民的工伤和教育机会都改变。这不是将 Anna 的 `fame` 加 100，而是让法律与行政机构执行新的规则。

## 11. 世界终局与代际体验

终局由真实的文明级变革、灾难或时代转折触发，可结束当前纪元并归档；不强制 2050 AI 叛乱等预设剧情。测试中需要有**最大模拟时长安全截断**，但它不是故事情节。

人物死亡后保留后代关系，允许继续观察后代及出生新生命。新生儿必须出生在当前或新世界的现实家庭里；不能通过账户选择任意富豪或历史人物做父母。历史档案永不因世界结束而变成废数据。

## 12. 成品应该是什么感受

玩家看到的不是一百条「今天努力工作」「关系+3」；他看到一段由真实人物、制度、工作、家庭和偶然机会形成的生活。他可以看见某个朋友几年后变成敌人，某次意外没有宏大意义，也可以追溯一项法律为什么改变了孩子的生活。世界继续残酷地前进，不保证公正，也不刻意讨好玩家。
