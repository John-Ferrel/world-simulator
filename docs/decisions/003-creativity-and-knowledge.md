# ADR 003 — executable creative definitions and bounded knowledge

The first pack exposes four action capabilities and three institution mechanisms. A generated guild, academy or council is a durable named organization with real members, treasury, upkeep, expiry, recruitment and succession. Academy research produces durable discovery identities only for an actual positive increase in the shipped knowledge/production hook. At the supported knowledge ceiling, further attempts report no practical improvement rather than inventing a new technology.

Agent policies are a separate versioned grammar: cooperation, knowledge seeking and scarcity avoidance. They alter future contact, research or migration opportunities, carry causal source IDs and expiry, and can spread through actual contact and acceptance. Published claims remain separate from canonical truth. These hooks allow novel social arrangements, not arbitrary generated physics or runtime code.

Daily token reservations cover both creation parsing and worker calls. Unknown usage on provider failure conservatively retains the reservation. Model output is version/deadline scoped and the simulator checks it again at execution time. Narrative candidates must be literal extracts from referenced committed facts; artistic freedom is intentionally restricted in this release.

A bereavement can radically change a close friend's/partner's/relative's goals. Hearing of an acquaintance's death creates a low-salience memory instead of automatically overturning identity. This correction follows the long-run quality audit, which found excessive grief/goal churn when all acquaintances counted as intimate ties.
