# ADR 018 — 出生立即落地，愿望解释异步有界

日期：2026-11-01
状态：accepted

## 背景

`simulator-1031` 要求出生深度编译，但不允许阻塞共享时钟。真实模型可能超时、返回非法 JSON 或不可用；出生本身必须立即成为世界事实。

## 决定

- 出生先在模拟器事务中创建人物/亲属关系/出生事件；API 立即返回 202 和请求 id。
- `v4_birth_contracts` 队列由独立 worker 消费；worker 调真实模型，严格校验 JSON。
- 模型只能输出：≤300 字读法、focus 枚举、最多 4 个 ±0.08 性格微调、≤200 字 taboo。任何额外字段、超界值、超能力/金钱文本被拒绝。
- 失败最多重试 3 次；之后保留原愿望，人物照常生活。
- 读法提交时锁世界/人物行并递增 revision；模拟器用旧 revision 保存会失败并在下一循环重试，不会覆盖读法。

## 后果

- 出生从不等待模型；模型不可用不阻塞世界。
- 当前只实现“愿望读法”，不是完整条件式 Life Contract；不声称 LLM 会创造机制或决定命运。
- 每次真实调用约 500–600 tokens（本切片实测）。

## 备选

- 同步调用模型后返回出生：违反不阻塞时钟，模型失败会阻止出生。
- 先返回模板读法再假装已编译：属于 fake success，明确拒绝。
