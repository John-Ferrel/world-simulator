# Phase 21 — Product Experience Audit

日期：2026-11-08  
方法：真实 dev server + Playwright Chromium 实际操作；注册、创建人物、出生、观察、读取日志、检查 DOM/Canvas 像素与地图；再用真实 Engine 跑 7 年儿童 cohort 验证 0–5 岁事件。  
证据：`docs/v4/phase-21-audit-initial.png`、`phase-21-audit-birth.png`、`phase-21-audit-observer.png`（修复前）、`phase-21-audit-early.png`、`phase-21-ui-first.png`（修复后）、`/tmp/opencode/audit21b.log`、`/tmp/opencode/early-engine.log`。

## 1. 第一次打开

登录页清楚表达了“观察而不是指挥”，视觉基调统一，出生页也能说明世界、家庭和愿望。问题：

- 登录页文案固定写“1900 年的真实地球”，但 v4 世界实际从 1912 年开始；这是产品口径不一致，不是机制错误。
- 页面标题/说明仍像 v1 地球模拟器，和实际维也纳 1912 切片有落差。
- 出生页的“此刻的世界”文本是静态时代说明，世界推进到 1930s/1940s 后仍显示 1912 年语境，容易误导。

## 2. 出生后立即看到什么

修复前：

- 日志有“出生”和“出生愿望成形”两条，但出生文本是通用的“在 X 出生，母亲抱着孩子，这间住处住了 N 口人”。
- 左侧人物区域空白：`.portrait` 计算高度只有 **2px**。原因是 `.person-pane` 是 flex column，`.pane` 有固定高度和 `overflow-y:auto`，`.portrait` 默认 `flex-shrink:1` 被压缩；Canvas 本身有 364 个非透明像素，但被 `overflow:hidden` 裁掉。这是“左侧人物消失”的直接原因。
- 右侧地图是手绘的维也纳示意图（`ViennaMap` SVG），不是世界地图；`WorldPane` 根本没有使用已有的 `EarthMap`/`countries.geojson`。
- 0–5 岁：真实浏览器等待一个世界年后仍然只有 1 条日志；Engine 里玩家出生角色的通用 infant scenes 存在，但 `rate` 很低，且大量 authored infant scenes 只对 `subjectIds: [Elisabeth]` 生效，玩家孩子不会触发。

修复后：

- 出生事件包含家庭细节：母亲/父亲姓名与职业、家庭现金/债务、兄弟姐妹数量、拥挤程度；不再是一句通用模板。
- 出生后立即看到人物大肖像、姓名、年龄、住处、家庭、愿望、世界位置和两条已提交事件。
- 日志中的“出生愿望成形”明确说明愿望只是机会与注意力，不是命令。

## 3. 左侧人物美术

修复前：完全不可见。  
修复后：`.portrait` 固定 260px，Canvas 216px 显示；LPC 分层纸娃娃可读，年龄缩放、死亡灰度、低健康标记、职业配件（医生/官员眼镜与外衣、学生背包、艺术家头巾）开始生效；素材失败时有姓名首字 fallback。

仍不够好的地方：

- LPC 资产本身是 64×64 地图小人，近景放大后细节有限；它不是 DoL 级别的精细纸娃娃。
- 当前只有少量服装/发型组合，职业配件是规则叠加，不是完整 wardrobe。
- 婴幼儿体型在 260px 框里偏小；需要更大的婴儿/儿童专用构图或摇篮/家庭场景。

## 4. 世界地图

修复前：`ViennaMap` 手绘多瑙河/内城/利奥波德城示意，无法让玩家感受到世界规模。  
修复后：`WorldMap` 使用 `apps/web/public/earth/countries.geojson`（177 个国家/地区轮廓）做等距圆柱投影；显示欧洲、地中海、北非与全球按钮；维也纳/克洛斯特新堡可点击；当前人物位置有金色脉冲环；支持滚轮缩放、拖动、全球/欧洲/人物视角。

仍不够好的地方：

- 默认视角是欧洲，不是全球；这是为了在 390px 右栏里保持可读性。
- 只有维也纳/克洛斯特新堡是真实可点击地点；其他世界城市是尺度参照，不参与 v4 模拟。
- 没有逐年历史国界；这是下一阶段数据工作。
- 地图没有显示迁移路线、战争战线或历史事件位置；目前只显示人物当前位置。

## 5. 五分钟观察体验

- 世界 30 秒/年；5 分钟约 10 年，足够看到童年、学校、家庭事件。
- 修复后 0–5 岁不再是空白：Engine 7 年测试产生 **16 条**儿童/家庭事件，包括第一句话、第一次笑、楼梯摔伤、家庭故事、第一个朋友、洗礼银勺被典当等。
- 日志仍是核心；右侧“时代”和“历史遗产”提供世界尺度，但历史进程卡偏多、偏解释性，容易压过个人故事。
- 当前缺少“新事件到达”的强反馈；刷新是 4 秒轮询，年份变化没有明显动画/提示。

## 6. 哪些系统实现了却对体验贡献很低

- **Macro Director / 历史进程**：存在，但在右栏以长文本卡片出现；玩家很难把它和“我的人”连起来。
- **Runtime content worker**：存在，但玩家看不到内容如何进入世界；没有“新故事已发布”的反馈。
- **State 参数**：大量 state 参数在日志/侧栏不可见；玩家只能从文本猜。
- **经济账本**：房租、债务、工资存在于事件效果，但没有家庭账本视图。
- **组织/Position**：有数据，但只有在特定事件/侧栏才露出；没有“我的组织”感。
- **地图地点**：修复后世界地图可定位，但点击城市只列在场人物；没有地点故事/历史层。
- **历史人物关系**：有 chip，但与普通关系的视觉层级不够分明。

## 7. 审计结论

Phase 21 的首要问题不是“再加内容”，而是：

1. 先让人物可见（flex bug）；
2. 先把地图变成真实世界（组件替换）；
3. 先让出生和 0–5 岁有连续故事（通用 infant/child scenes + 高 rate + 家庭文本）；
4. 再让高戏剧内容进入自然人生（drama pack + adaptive contexts + 分布）。

这四项已进入本轮实现；美术资产精度、历史边界、经济/组织可视化和新事件反馈仍是后续工作。
