# ADR 006 — 历史条件与可执行社会，独立于玩家观察身份

用户将目标扩大到万人以上注册人物、世界历史人物出场以及欧陆风云/钢铁雄心式反事实。上一版历史目录不构成足够的游戏复杂度。本轮增加可执行的政府、社会、冲突与世界线状态；默认只在地球场景启用，既有虚构世界保持回归比较基线。

每种机制保存实际前提、成本、影响对象、期限和因果引用。固定时间只是历史机会窗口；政体、战争、人物生死等前提不成立时必须分叉。原历史事实是资料来源，模拟偏离不能伪称发生过的真实事件。

Luna 子代理分别实现地缘政治、社会网络和世界线/人物名录，主代理拥有集成接口与验收。死亡统一经模拟核心处理遗产、亲友和计划，不能由子模块简单写 death 绕过流程。杀戮和迫害带责任、受害、避难与社会后果，不采用美化暴行的得分或显示。

万人规模先消除全量嵌套扫描和逐事件数据库往返，再测实际账户/人物/状态推进与恢复。单体 JSONB 快照仍是当前权威存储；如果序列化、历史体积或写锁实测超出目标，必须如实记录并继续改存储，不能拿无数据库 headless 数字代替生产容量。
