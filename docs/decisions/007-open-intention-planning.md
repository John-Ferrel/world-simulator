# ADR 007 — 自由意图，固定执行语法

**日期：2026-10-30**  
**状态：已采用**

## 背景

开放历史模拟不能把人物发展限定为若干预写世界线；同时，外部模型输出是不可信输入，不能直接操作世界状态或创造运行时机制。人物需要能根据记忆、失业、丧亲、关系、政治变化和失败结果改变方向，而模拟器仍须保证资源、因果、权限与持久化可检查。

## 决定

将“想做什么”与“世界允许怎样执行”分开。异步 deliberation worker 把人物观察、已知对象和带 ID 的记忆交给模型。模型返回自由意图、理由、证据 ID 和有限多步计划。它可以提出新的事业或项目名称，不需要从预设剧情列表中挑选。

执行能力采用版本化、严格校验的固定语法：练习、求职、照护、社交、迁移、组织、请愿、研究、传播、援助、项目、政治活动、外交协商与信仰实践。语义编译器只把明确的自然语言动作映射到这些既有动作；多余字段、任意代码、未知动作、越界目标和未观察证据会被拒绝。未支持的创意可以作为意图或研究问题表达，但不会凭文本获得新的物理效果。

worker 只将有效提案标记为 ready。模拟器是唯一权威写入者，在提交时重验人物版本、截止时间、观察证据、目标范围、资格与可用资源；之后推进计划并产生可追溯事件。资金、时长、失败、关系变化和行动后果由模拟规则决定。模型迟到、失败或预算耗尽时，确定性规则计划继续维持日常模拟。

## 原因与替代方案

- 纯预设剧情线容易与真实人物处境脱节，不能在失败或重大经历后形成新的方向。
- 任意模型脚本、开放效果字段或让模型直接更新世界，会破坏资源守恒、历史不可变和可复现性，故不采用。
- 纯规则规划可作为模型失败时的 fallback，但不足以表达基于个人经历的开放意图，所以保留为后备而非唯一规划方式。

固定动作语法不是固定故事：模型可以自由表达目的和项目名称，模拟器只执行已有、受限且可验证的机制。

## 验证证据

`tests/planning.test.ts`、`tests/planning-compiler.test.ts` 与 `tests/model-planning-worker.test.ts` 覆盖 schema、语义编译、真实 mock HTTP 子进程、ready 与 world 写入分离、过期版本拒绝、目标范围以及任意动作/效果拒绝。当前全套 PostgreSQL 集成记录为 94 项通过，定向套件为 18 项通过。

一次真实 API 调用记录消耗 402 tokens，产生三步提案，通过语义编译并在只读世界快照上被模拟；快照未写回线上世界。该记录证明一次调用链成功，不证明生产模型持续可用或所有提案会被采用。见 [`real-planner-repair.json`](../metrics/real-planner-repair.json)。

## 后果与边界

系统可以实现开放目标和有因果的重规划，但模型输出始终受既有动作语法限制。未知能力不会成为奇迹。模型服务不稳定、费用预算耗尽或超时会降低计划多样性，但不阻塞共享模拟时钟。

这项决定不构成完整历史复原。地区索引使用现代边界；战争和宗教是抽象社会/资源过程；历史资料只覆盖实际导入的条目。12,000 人单机数据库负载是注册与推进测试，不是并发浏览器 SLA。最终浏览器、备份恢复和 Docker Compose 验收另行记录。
