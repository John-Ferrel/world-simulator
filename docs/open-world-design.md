# 开放历史人生：执行框架与反馈回路

## 核心承诺

框架规定可执行动作、资源、权限、时空与因果；人物的意图、具体项目、路线与重规划由模型结合实际处境提出。史料提供背景、压力和机会，不把玩家限制在预写的故事树里。一次成功、失败或重大经历都会改变下一次规划的输入。

## 人物循环

1. 读取当下年龄、职业、性格、需求、意图、亲友、信仰/政治归属、当地经济与政治环境，以及真实观察到的事件。
2. 模型提出新意图、理由和有限长度的多步计划，可以给企业、作品、研究、组织或思想使用新名字。
3. 编译器把可识别语义映射到受支持机制；保留映射记录。未知能力、额外效果字段、任意代码和越界目标被拒绝。
4. 模拟器核对资金、资格、位置、时长、人物版本与证据，再执行每一步。模型没有“宣告成功”的权限。
5. 行动付款、耗时、改变技能/职业/关系、形成持久组织/作品/发现或政治影响。项目会因资金、健康、目标变化而失败。
6. 丧亲、失业、局势变化、目标不在场等会中止旧安排、清理进行中的项目，并提交新的规划需要。验证失败的原因也会回到下一轮上下文。
7. 模型迟到、失败或预算不足时，规则层维持工作、学习、生活和有明确来源的保守计划；共享时钟继续前进。

计划执行机制包括练习、求职、照护、社交、迁移、组织、请愿、研究、传播、援助、持续项目、政治活动、外交协商和个人信念实践。名称和目的开放，机械效果有界。政务工作者或历史人物标签不会自动授予国家指挥权；外交必须有实际领导资格和可接触的国家关系。

## 相互作用的系统

| 系统       | 持久状态                                                   | 实际影响                                                                                             |
| ---------- | ---------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| 个人与家庭 | 出生、健康、技能、需求、职业、亲属、伴侣、依附、导师、恩怨 | 工资、照护转账、学习、死亡继承、悲伤和目标改变                                                       |
| 社会与信仰 | 阶层、地方文化、明确的信念、社团、会费、互助、政治归属     | 关系、救济、社会流动、归属需求、改革诉求和失信                                                       |
| 劳动冲突   | 工会、停工窗口、参加者、救济资金、破坏停工的关系证据       | 实际工资与产出变化、人际裂痕、政治压力；团体解散不自动抹去仍持有的信念                               |
| 政府       | 政体、党派、利益集团、选举参与、劳动/宗教/新闻政策         | 税收和拨款、就业、合法性、镇压、政变与政体转换                                                       |
| 外交       | 关系、争端、联盟、制裁、停火及证据                         | 真实运输容量、军需和贸易，联盟援助，开战条件与协商和平                                               |
| 工业       | 煤、矿石、钢、油、军备、药品、配方、价格、产能、投资       | 输入不足不能生产；财政有收款方；交易与消耗可核算，军队会缺装备和燃料                                 |
| 战争       | 阵营、动员标签、前线、补给、占领、伤亡、和平               | 人口与粮食损失、领土和赔偿、个体风险、亲属和社会后果；不靠固定八年计时结束战争                       |
| 迫害       | 实施方、抽象目标群体、地域、证据、死亡、流离与问责         | 实际人口后果、个人危险、合法性和外交制裁；不设置暴行奖励                                             |
| 历史输入   | 有来源的时间、日期精度、地域、参与方和已观察前因           | 自然灾害影响受现状改变；跨国战争资料先进入外交压力，实际宣战依赖当前世界；国内政治参与可改变冲突走向 |
| 历史人物   | 来源身份、出生精度、出生地映射、职业线索与模拟身份         | 可以从儿童、成人或老年人口中进入；不保证活到成年，不按史实强制死亡、成功、掌权或完成成就             |

## 因果示例

- 工人因失业和物价压力组织互助、停工；短期收入下降和社团救济改变家庭处境，持续政治压力影响法律与党派，失败或背叛会改变关系和个人计划。
- 史料提示一次国际危机；已有联盟或政治改革可以降低升级压力，具有资格的人物可以筹划外交。发生战争后，工业、财政和前线决定进展，协商、补给崩溃或实际战局推动和平。
- 医生提出新的救护事业，先工作筹资，再研究或组建互助机构；资源与同伴不足会失败。结果进入其记忆和下一轮模型上下文，而非解锁预置“医生世界线”。
- 某位历史人物在模拟中早逝，其个人经历结束，依赖其存活的史料适用性发生变化；其他人仍可通过实际组织、行动和政治环境形成新的历史。

## 万人架构

每位活人都接受生理、经济和关系基础更新。地区、人物、路线和伤亡使用索引；强关系持续更新，新接触和工作组织机会轮转。模型任务有公平调度、观察版本、截止时间和全局预算，不承诺每人每月一次模型调用。

模拟器为唯一写入方；模型 worker 仅提交提案。世界、修订、事件、日志与 outbox 在同一事务中提交，事件批量写入。回放源于提交历史，不能用当前心理反推过去。基准在隔离数据库创建真实账户和角色，覆盖推进与精确恢复；不会把万人注册角色与万人并发浏览混为一谈。

## 明确边界

这是有多个相互作用系统的可运行实现，不是《欧陆风云》或《钢铁雄心》的完整复刻。当前地图仍使用现代地理索引；政体与资源的初始分布是明示的场景近似。没有逐年历史国界/殖民关系、逐宗教人口普查、完整军事编制/海空军单位、遗传模型或全商品经济。

历史人物包覆盖的是官方 Pantheon 数据中符合本包筛选条件的记录，不等于全部知名人物。历史冲突数据有明确时期、映射与排除记录。长时段人口、损失和经济参数尚未校准为现实预测；单机万人存档验证也不等于生产并发承诺。
