# 010 — 日志增量按人物身份保存并兼容旧记录

旧日志每月保存完整人物数组，包括此前早已死亡且没有变化的人物。万人和长时间推进会重复存储大量不变人生记录。

新提交采用 `world-state-patch/v2`：普通顶层变更放在 `set`，删除放在 `remove`；人物按 ID 保存变更、删除，仅新增/删除/重排时保存顺序。检查点仍是完整状态。恢复器先识别格式，再应用记录的数据，不调用现版本规则重新模拟历史；旧浅补丁仍可读取。

补丁保留 JSONB 的 undefined 语义、删除与顺序，检查重复身份、格式、大小和危险键；任何链路错误仍由 revision 和 canonical checksum 拒绝。未变人物不进入 upsert，且不因差量恢复而修改输入检查点对象。

没有采用压缩后不检查的事件段，也没有删除死者来换取体积指标。这个优化只降低重复日志，不等于已解决所有长期数据增长：完整世界行、其他大集合、索引与备份容量仍需实测。
