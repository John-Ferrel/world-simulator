# 009 — 人物意图受旅途、身份、政治资格和军需共同约束

执行框架继续固定，人物和模型可以自由提出意图。新增机制并非预写世界线：没有按历史年份指定谁上台、谁必然改信或谁赢战争。

- 个人旅程使用实际路线、模式、距离、受限容量、路费和途中粮食。人物在途中保留最后确认的城市，但不在该城工作、学习、研究、社交或参加权力竞争；抵达是单独提交的事实。城市级模型没有逐坐标旅人轨迹，行程失败回到最后确认地点的记载不能解释成精确返程模拟。
- 全部战争先动员，再共享国家库存与路网容量，最后逐战线计算兵力与后果。相同军需不能复制给多个战区；伤亡从动员国的人口扣除，不能因前线被占领而错误扣到无关国家。海运表示有限民用运输和受阻能力，没有据此宣称舰队/海空战。
- 领导人死亡、失能、长期缺席导致真实权力真空。成年、在地、服务/组织/军职和社会支持决定候选资格；选举联盟、改革和政变都有成本、失败与后续政策效果。关闭旧的按野心直接任命以及定期免费切换政体。
- 价值改变由具体经历驱动。丧亲、被救助、背叛、迫害、成功失败不再产生相同方向的数值变化。宗教/政治身份需要本人观察或参与的证据；世界其他地方发生的事件不能自动成为个人认知。当前月的自由意图、规则行动和社会接触继续产生新的因果。
- 模型不可用时的规则计划根据现实处境选择求职、照料、互助、学习、组织、迁徙或有证据的政治活动。它不会给人物默认政治立场，付不起钱也仍可尝试求职；成功率与岗位条件照常约束结果。规则计划有明确来源，不冒充模型输出。

这些新状态由原有模拟器单写者提交，旧历史不重算。新增模块都采用惰性初始化和每月幂等标记，并以独立与跨系统反事实验证。
