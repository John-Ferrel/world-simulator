## 真实限制与外部事项

- 历史不是完整逐年复原；现代城市/地图索引、人口估计、行政回退及程序化领导人有明确抽象。目录不含所有知名人物，来源输入不能代替世界机制。
- 没有完整海空军、逐单位战术、完整司法体系或完整宗教人口史。战损系数、自治财政比例等是情景规则，未经历史拟合。
- 150年场景仍有大量日常事件、目标变化和机构解散；并不据此保证所有世界线都有同等戏剧性。完整计数、实际因果链与样本保留供复核。
- 50k每日模型预算下多数人物由规则后备运行；未验证万人并发模型规划、生产SLA或公网部署。Docker daemon不可用，Compose端到端启动未验证。
- CShapes城市点主权资料为CC BY-NC-SA4.0，当前非商业本地使用；商业发布必须另取许可或换源。Pantheon为CC BY-SA4.0，UCDP为CC BY4.0；素材许可随项目保留。
