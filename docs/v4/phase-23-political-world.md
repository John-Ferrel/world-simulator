## 2. 1912 世界

1912 快照不是“现代国家贴上旧年份”，而是：

- **奥匈帝国**：弗朗茨·约瑟夫一世；奥地利首相卡尔·冯·施蒂尔克；外交大臣利奥波德·贝希托尔德；SDAP、基督教社会党、德意志民族联盟、波兰俱乐部、捷克民族社会党；二元制、民族问题、普选、巴尔干、工人运动、反犹主义。
- **德意志帝国**：威廉二世；贝特曼-霍尔维格；SPD、中央党、民族自由党、保守党、进步人民党；海军竞赛、普鲁士三级选举、阿尔萨斯-洛林、殖民地。
- **俄罗斯帝国**：尼古拉二世；科科夫佐夫；立宪民主党、十月党、社会革命党、RSDLP、俄罗斯人民联盟；杜马与专制、土地、民族、革命、巴尔干。
- **奥斯曼帝国**：穆罕默德五世；1912 年大维齐尔链为赛义德帕夏 → 穆赫塔尔帕夏 → 卡米勒帕夏，1913 年后谢夫凯特/赛义德·哈利姆/塔拉特；统一与进步委员会、自由与协约党；巴尔干失地、阿拉伯省份、亚美尼亚改革、列强干预。
- **大英帝国**：乔治五世；阿斯奎斯；自由党、保守党/统一党、工党、爱尔兰议会党；爱尔兰自治、妇女参政、工人罢工、海军竞赛。
- **法兰西第三共和国**：法利埃/普恩加莱；激进社会党、共和联盟、SFIO、法兰西行动；政教分离、劳工、对德复仇、殖民。
- **意大利王国**：维托里奥·埃马努埃莱三世；焦利蒂；自由联盟、社会党、民族主义协会、人民党；利比亚、选举权、irredentism。
- **塞尔维亚、保加利亚、罗马尼亚、希腊**：各自的君主、首相、政党与巴尔干战争立场。
- **美国、日本、中国**：塔夫脱/威尔逊、明治/大正、孙中山/袁世凯；各自国内政治与对外关系。

地图上，奥匈帝国用现代奥地利、匈牙利、捷克、斯洛伐克、斯洛文尼亚、克罗地亚、波黑着色；俄罗斯帝国覆盖俄罗斯、芬兰、波罗的海、白俄罗斯、乌克兰、摩尔多瓦、高加索与中亚；奥斯曼覆盖土耳其、叙利亚、伊拉克、以色列/巴勒斯坦、约旦、黎巴嫩；英法帝国覆盖本土与部分殖民地。所有条目带 `approximate: true` 和说明。

## 3. 时代变化

- **1918**：帝国崩溃、德意志共和国、苏俄、匈牙利革命、捷克斯洛伐克、南斯拉夫、波兰、土耳其独立战争、凡尔赛/圣日耳曼/特里亚农、 influenza、妇女选举权。
- **1938**：Anschluss 后奥地利并入大德意志；慕尼黑协定；波兰、匈牙利、罗马尼亚、南斯拉夫、苏联、英法绥靖、意大利法西斯、西班牙佛朗哥、土耳其、美国、日本、中国。
- **1945**：奥地利四国占领与伦纳政府；德国占领/1949 分裂；波兰、捷克斯洛伐克、匈牙利、南斯拉夫、希腊、土耳其、英国、法国、意大利、美国、日本、中国；大屠杀之后、去纳粹化、冷战开始。
- **1955**：奥地利国家条约与永久中立；联邦德国/民主德国；苏联、捷克斯洛伐克、波兰、匈牙利、南斯拉夫、英国、法国、意大利、美国、日本、中国、西班牙。
- **1991**：冷战后、欧盟一体化、南斯拉夫战争、俄罗斯联邦、捷克/斯洛伐克分离、波兰/匈牙利转型。

## 4. 与现有机制互通

### Organization / Position

在 `vienna-history-people.ts` 中新增真实组织：

- `org-christian-social-party`：基督教社会党，维也纳市政庇护网络。
- `org-german-national-association`：德意志民族联盟。
- `org-austrian-state-1912`：k.k. Ministerium des Innern（维也纳），国家行政机构。
- 新增职位：`pos-christian-social-leader`、`pos-german-national-leader`、`pos-habsburg-emperor-1912`、`pos-austrian-minister-president-1912`。

这些使用现有 `Organization` / `Position` 契约，有 `authorityRules`、`treasury`、`monthlyRevenue`、`positions`，不是只存在于文本里的“政党”。

### State / Event

- 新 drama pack 使用 `political-suspect`、`under-investigation`、`blacklisted`、`office-patronage`、`public-scandal`、`fame` 等现有 State。
- 新闻生成器写入 `political_tension`、`war_fear`、`persecution_pressure`、`economic_anxiety` 四个压力键，内容可用 `pressure` 条件读取。
- 政治世界不直接改写已提交事件；它提供背景、压力与可查询资料。

### API

- `GET /api/v4/world` 返回 `politicalWorld`（当前年份快照）。
- `GET /api/v4/political-world?year=1912` 可查询任意年份。
- 快照包含 `polities`、`leaders`、`parties`、`tensions`、`viennaPolity`、`map`、`sources`、`note`。

## 5. 真实数据例子

1912 政治面板实际显示：

- 维也纳所属：奥匈帝国。
- 国家元首：弗朗茨·约瑟夫一世。
- 政府首脑：卡尔·冯·施蒂尔克。
- 外交：利奥波德·贝希托尔德。
- 政党：社会民主工人党（主要）、基督教社会党（主要）、德意志民族联盟（反对）、波兰俱乐部（反对）、捷克民族社会党（反对）。
- 矛盾：二元制权力分配、民族诉求、普选与议会阻塞、巴尔干外交、工人运动、反犹主义。

1938 地图把奥地利着色为大德意志帝国；1945 把奥地利着色为被占领的奥地利；1955 回到奥地利第二共和国。这些变化来自 `politicalSnapshot(year)` 的政权周期，不是地图组件硬编码。

## 6. 限制

- **不是完整政治模拟**：没有逐国议会投票、联合政府谈判、外交博弈或军事推演；只有时代快照、组织/职位、压力和新闻。
- **地图是近似政权归属**：现代国家几何按历史政权分组，无法表达加利西亚、特兰西瓦尼亚、伏伊伏丁那、南蒂罗尔、殖民地边界、占领区前线。
- **1938–1945 的占领/ client state 被合并**：南斯拉夫、波兰、捷克斯洛伐克等只能以国家级别叠层表示；大屠杀与营地不在几何层。
- **部分领袖/日期仍是 tertiary source**：Wikipedia/Britannica/Wien Geschichte Wiki/USHMM；未做逐条档案验证。研究简报列出了不确定项。
- **历史人物多数是 reference public figures**，不是全部进入模拟；只有少数（弗洛伊德、阿德勒、克劳斯、施尼茨勒）是普通 Person。
- **1991 后的南斯拉夫继承国**只做了塞尔维亚/黑山与部分邻国；波斯尼亚、克罗地亚、斯洛文尼亚、马其顿、科索沃的独立政权未逐一展开。
- **没有玩家可操作的国家/政党管理 UI**；这是观察世界，不是大战略游戏。

## 7. 后续扩展

1. 用 CShapes 2.0 或 Historical Basemaps 的简化几何替换国家级别叠层；先解决许可与非商业条款。
2. 增加 1920s/1930s 的奥地利政党/准军事组织与政治暴力事件。
3. 把政治组织成员资格、职位任命、调查/黑名单接入更多现有 Event/State。
4. 为每个时代补 3–5 个“人物—政党—新闻”桥接 kernel，让政治背景更常进入个人故事。
5. 增加殖民地/占领区的子国家几何与争议边界图层。
