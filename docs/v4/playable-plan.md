# 可玩版本关键路径（Playable v4）

更新：2026-11-02。目标不是继续堆 Phase 5 指标，而是交付一个能实际打开、注册、创建孩子、持续观察且不产生荒谬记录的共享人生模拟器。

## 验收定义

1. `pnpm dev` 启动后，新观察者能注册并创建孩子。
2. 孩子进入一个有真实住址、在世监护人和合理年龄结构的家庭，出生事件立即可读。
3. 孩子在 1912–2000 年间持续产生可读事件，至少覆盖童年、学校/工作、成年关系、老年或明确死亡。
4. 已故人物显示卒年/死因，年龄不再继续增长；家属列表不会把死者算作当前住户容量。
5. 个人日志没有 `None`、内部枚举、未解析模板、空参与者和无原因死亡；死因可读。
6. 求偶/生育不会被同一个人每年重复刷出；家庭规模受住址容量约束，不出现单户 60+ 在世人口。
7. 战后（1945–2000）仍有生活内容，世界不会被冻结在 1912 年参数与 1918 年时代记录。
8. 活动世界和归档世界不被删除；新世界使用新 ID，旧历史只读保留。
9. 自动测试覆盖上述行为；浏览器 e2e 真实注册、出生、日志、家庭、地图。

## 顺序

1. 先修 engine 家庭容量/死亡/出生/求偶，避免新内容建立在错误人口结构上。
2. 接入战后内容与时代记录，保证 1945 后不是空白。
3. API/UI 修复已故年龄、标题、死因。
4. 跑无头 80 年 playtest，检查每个十年的事件、家庭规模、重复场景、空白日志。
5. 修正发现的问题，跑 v4 全量、全量、build、e2e。
6. 当前 `world-vienna-1912-vmvyrtquw` 已在 2001 年自然归档；自动启动的无玩家 `world-vienna-1912-vmvytn6cs` 将归档并用最终代码创建新 1912 世界，不删除任何档案。

## 非目标

- 不新建 v5。
- 不重写宏观/统计/内容运行时。
- 不把游戏改成频繁点击的互动小说。
- 不伪造 20k 生产容量或多地区长期 LLM 验收。
