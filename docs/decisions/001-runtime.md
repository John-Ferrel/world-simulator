# ADR 001 — explicit pure monthly state transitions

Use a strict TypeScript monorepo with PostgreSQL and separate API/simulator/worker processes. Monthly cadence is the default 20 minutes/year divided by twelve; async jobs never block advancement. Use deterministic entity-local hash PRNG rather than mutable global random state. Store structural top-level patches in a transactional journal, alongside periodic complete checkpoints, rather than relying on narration or rerunning changed binaries. This favors inspectable recovery over normalized hot-path complexity at the initial 1,000-person target. The current-state projection is JSONB; identity/auth/commands/jobs/events/outbox/checkpoints/maps are independently indexed SQL tables. Production scaling beyond measured targets requires partitioning the state projection.

Narrative generation uses an extractive contract: candidate passages must be literal substrings of a referenced committed event. Unsupported prose is rejected and the deterministic factual renderer remains available. This intentionally limits prose freedom to preserve factual grounding; new canonical events are never created from narration. Optional natural-language creation maps only to bounded occupations and temperament, with a local keyword fallback and explicit normalization review.
