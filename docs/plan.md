## 本轮已完成的实际接入

- 政治继任、缺席/失能权力真空、有资格的联盟和改革政变；停用 Earth 的旧野心任命与免费政体切换。
- 按直接经历与同地可信网络更新身份/信念；不逐人复制全球事件，也不把传闻升为事实。
- 按真实路线、费用、口粮、封锁和容量旅行；在途冻结当地就业、研究、社交和任职。拘留与死亡同样关闭不应继续的行动。
- 所有战争共享一次军需路网分配；动员国承担军队伤亡、零兵力没有战斗暴露。战争事件保留补给和前线原因。
- CShapes 1900 城市点基线只初始化新世界；现代 regionId 与当前 polityId 分离，保留未匹配点的不确定性。殖民财政、属地外交和自治/独立限制已接入。
- 群众运动有真实组织者、资金和持续支持；自治/独立需要支持、财政与宗主状态，不凭三个人的口号令强盛帝国消失。
- 工业产能随真实城市控制转移，国家库存不复制；新行政区实际获得政府和外交状态，独立中立地区不继续承受过时战线。
- 旧地理重复 Niamey ID 有幂等修复。国家税收与合法性按人口汇总，细分地图点不会凭空加重国家压力。
- journal v2 人物增量已接入并兼容旧格式；过期人物模型任务在预算预留前关闭，追赶时不批量发起注定过期的付费规划。
