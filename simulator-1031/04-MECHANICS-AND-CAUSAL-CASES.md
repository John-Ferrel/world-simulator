# 世界人生 — 可执行机制定义与具体因果案例

这是对 `01/02` 的进一步补充：**把机制写成输入、选择、公式、状态迁移与多方后果**，减少 Coding Agent 自行猜测「人物到底如何生活」的空间。所有数值案例均是**演算示例而非真实历史统计**。正式数值必须由 1900 年历史/地区资料校准；公式为建议实现语义，允许在源码审计后保留更成熟的现有实现。

## 1. 每个模拟月究竟计算什么？

**不要每个人每天主动触发一次随机行为。** 单个 30 秒/年的世界，30 秒代表 12 个月；各月约 2.5 秒墙钟时预算。真正处理以日期优先队列为基础，可在月内有具体日的重大事件。

按领域依赖组织一个模拟结算周期（需要明确事务优先级）：

1. 读取已提交的战争、气候、疫情、地方法律、物价、工业能力、交通可用性。
2. 组织/工厂/医院/学校本月公布实际容量：多少职位、工资、病床、学额、粮食、药品、经费可用。
3. 结算人口层的资源生产/消费/供需、必要的年龄/出生/死亡风险候选（不在此对具名人物重复死亡结算）。
4. 提取到期的具名事务：工资支付、申请结果、治疗进展、项目截止日、学校学期、军役、家庭迁徙、重大健康状态变化。
5. 角色或组织按实际需求向存在的对象发出提议；对方独立回复，资源/权限/在场条件经最终裁决。
6. 将真实后果原子写入权威状态，并发布 `on_birth/on_death/on_contract_changed/on_event_committed/...` 供内容匹配。
7. 以事件显著性产生可读历史里程碑，记录因果而不是每月流水账。

**精度不是固定的：** 户籍年龄/人口可以月结算、工资按发薪周期、学业按学期、军役战役按必要日期、政治运动按阶段。一个几个月没有事件的家庭无需强制制造微小戏剧。

## 2. 婴儿、家庭与养育：出生就能产生真正不同的命运

### 状态

`Household` 要有实际住房、现金、食物可及性、收入成员、支出/税/租、债务、监护人、照护负担与子女；`Child` 有营养、身体状况、受教育资格、对照护者的记忆及依赖。除突发死亡和遗弃等情境外，婴儿多数决策由监护者执行。

### 具体规则

- 新生儿食物/护理需求来自年龄及身体状态，由监护人的收入、可用时间和卫生条件满足；长期缺口改变疾病暴露和生存风险。
- 父母、其他亲属、孤儿院或社会救助机构的照护能力必须有实际人数/资金/容量；不能无限领养。
- 监护权与亲子关系不同：亲生父亲也可能失联，孩子的实际监护人是外祖母。
- 父母死亡触发遗产/债务、抚养安排、居住搬迁、照护可用性变化；**不**直接等于孩子获得“孤独+10”。孩子对死亡的理解会受年龄、同住经历与信息来源影响。

### 案例

一名父亲在军中死亡，家庭现金减少，但祖父母可能提供住房，国家可能有抚恤，母亲可能重新就业。另一名孩子没有亲属资源，家庭走向贫困。**战争与两段人生之间的差别来自家庭网络和制度**，不是骰出两个不同文本。

## 3. 疾病与死亡：少数可靠模型比“每年死亡概率”正确

### 3.1 竞争风险模型

按当前年龄、地区、性别/身体、年代等给定**基线死亡危险率** `λ_base`（单位：每模拟年），疾病、战场、饥饿、职业风险增加原因危险率。若某段时间 `Δt` 年内率近似恒定：

`P(death during Δt) = 1 - exp[-(λ_base + λ_disease + λ_war + λ_famine + λ_job) × Δt]`

抽到死亡后，按各原因危险率比例选择主要死因，再检查治疗、暴露程度与因果事件。若战争与流行病已由另一专门系统分摊伤亡，必须**从基线危险率里扣除/拆出相应来源**，避免两次计数。出生/死亡均必须与人口聚合账本对齐。

### 3.2 临床与社会后果

疾病是一个过程：暴露 → 潜伏/感染 → 临床影响 → 治疗/恢复/并发/死亡。它改变实际劳动、照护、学习、经济和传染风险；医院有可用医生、床位和药品；医学能力随历史技术变化。疾病日志应说明确切诊断存在不确定性时只是“被认为患病”。

### 3.3 参数校准

从 Human Mortality Database 等按国家/年代/年龄的来源校准可得地区，空白地区用不确定性更高的参数与附近社会条件推估并标注。不能简单把全球 1900 年人物的死亡率设为相同的 0.02，也不能保证玩家孩子长大。

## 4. 教育：入学是一种竞争与长期承诺

学校具有年龄/性别/地区/阶层在当时的资格制度、师资、学额、学费、学期、学术或职业课程。一个孩子能否升学由**两阶段行为**决定：

1. 家庭/本人是否申请、是否愿意支付、是否得到教师推荐、是否受政策限制；可同时存在其他生活目标。
2. 学校在截止时间根据资格和名额作招生决策，最后结算家庭现金、在读状态及课程；未入学不等于立即转为工人。

**示意演算**（虚构数字）：家庭月收入 60，必须开支 51，学费 14，剩余资金 9；学生申请奖学金 10，可用其他亲属捐助 5，则学费资金从不足变成可能满足。但是若当地制度禁止某种入学资格，即使有钱也不能立刻入学，除非特殊制度改变/学校另有名额。只有完成真实学业/考试才能拥有毕业资格。

老师是一个具名或可永久具名的人，可以因为过去课堂经历主动推荐，不应由事件刚出现时临时拼一个“慈祥教师”。

## 5. 雇佣与工厂：钱与工作必须有真实往来

**招聘来源**：企业某职位的计划岗位、工资预算、技术要求、地区劳动供给、工作条件。**求职者来源**：个人需要、技能、关系介绍、地点与交通、身份资格。两侧在符合条件后各自打分：企业看技能/用人成本/风险，工人看工资/工时/安全/未来计划/家庭义务。

达成真实雇佣合同：雇员、雇主、岗位、薪酬、日期、班次、资格、履约义务；工资从企业现金转入家庭/个人现金，不得空降。企业生产并卖出货物获得收入；如果连续亏损，就需要借贷、降薪、关闭岗位或破产，而不是永远有钱发薪。

**示意演算**：印刷厂本月收入 1,000，原料与维护 400，工资预算 430，税/贷款 110，剩余 60。Josef 受伤无法承担排字工作，企业若暂停他月薪 30，Josef 家庭月底少收 30；企业不应在停薪的同时再重复支付给他。后续赔偿若发生，从企业或保险账户真实划出。

## 6. 社会交往：不是每月 friendship += 1

### 6.1 真实接触机会

**接触候选集合：** 同住家庭、工作场所/班次、学校班级、同组织与共同项目、交通与同场活动。索引保证候选真实存在且有时间重叠。关系紧密的人可能在不同城市通过信件维系联系，但信息传播有延迟和费用。特殊导演聚会是新增**真实活动和邀请**，不是全局随机强配人物。

### 6.2 方向性的关系

关系至少区分 `trust`（相信说辞）、`affection`（情感）、`obligation`（承担义务）、`respect`（能力/道德评估）、`fear`（威胁感知）等**不同维度**；这只是支持行为判断的数值辅助，不是人格的完整语义。共同具体经历以事实 ID 存档，各人主观 `Knowledge` 与 `Interpretation` 可以不同。

### 6.3 具有回应的互动

A 请求 B 在诉讼中作证：A 有真实利益，B 可能有工作风险、对 A 的关系、对事实的记忆。B 可以拒绝或在压力下撒谎。此时世界中的法律制度决定证言如何被法院使用；A 的意图不能直接将 B 改成同意。B 有异能读心也不能凭空获得所有证据，需要合法的感知触发与代价。

## 7. 项目（Project）与组织：如何从小人物进入世界史

任何持续活动用有实际参与者的多阶段项目表示：

`准备 → 获取资格/人/资源 → 发起 → 争取回应 → 推进 → 成功/失败/撤回/改道 → 产生新事务`。

**政治改革案例：** 一群受工伤影响的工人先尝试找工会/律师，组织收集真实案件、招募、筹款、游说议会，反对组织可以说服工人退出、推动镇压或提出反方案。改革成功需要真实政治权力主体通过法律，而不是人物威望超过阈值。成功后法律向所有工伤争议提供不同的程序条件；即使原倡议者死亡，制度继续生效或被新的政权废止。

**组织内部机制：** 职位权力、投票/委任/军令规则、成员参与意愿、资源、对外联盟；普通匿名成员可按 POP 群体模型参与组织态度/罢工人数，重要领导和不同意见者则作为具名人物产生可追踪的选择。不要把普通成员忽略，亦无需每人调用 LLM 投一票。

## 8. 战争/流亡/历史人物：宏观冲击如何落入家庭

**战争前提**：国家或武装组织具有战斗单位、兵员来源、补给、工业、地理与政治目标；外交联盟、动员和政治组织决定军事行动可能性。战争不必须复刻 1914。

**召集**：特定地区年龄与职业的征召人群按当前法律选出，具名人物依据真实资格、地点和身份进入军队；抽象人口同步扣除兵员进入军队池。医务人员和难民也有真实迁移与劳动影响。

**战场**：军队承担损耗，具名士兵的具体受伤/死亡必须与单位整体战损对账。军队与地方食品/运力需求改变城市工厂、物价、家庭和医疗能力。战线变化后难民流向真实可达的地区，增加这些地区的住房、工作及医疗压力。

**真实历史人物**：以相关城市/时期/组织为行动窗口，已知史实与不确知补全有明确区别。1913 年维也纳咖啡馆可以由导演创建活动，但谁符合出行、地点、存活和社交条件需要裁决；不得为了名场面把不在城里的人硬塞到同一张桌子。

## 9. 异常能力与“系统流”怎样与普通规则共用执行器

以“识破故意谎言但损失记忆”为例：

```yaml
capability:
  id: discern_deception
  trigger: social.communication_received
  guards:
    - target_statement_is_observed
    - listener_conscious
    - remaining_usable_memories >= 1
  observations:
    detect: speaker_intends_to_mislead
    distinguish_honest_mistake: true
  costs:
    - remove_one_high_salience_personal_memory
    - create_private_health_stress
  outputs:
    - create_belief_about_speaker_statement
    - record_ability_activation
```

这是目标语义。关键不在 YAML，而在 runtime 能访问**说话者的当时意图与信念**，并有按条件消耗个人主观记忆的事务。如果引擎只有 `trust ±10`，这个能力根本不可表达。若超常能力凭空造出某种不支持的新资源/物理效果，要么编译出受限近似机制，要么走新的执行模块部署流程，不能凭一句模型断言就算实现。

“系统流”可以建成角色私有的 **RuleSet + Goal/Reward Generator**：在角色满足世界事实时发布私人任务和奖励；任务必须符合世界内可获得的技能、道具、权限和代价。系统不可以命令别的真人账户，也不可以直接把整个城市变成私人财产。

## 10. History Director 的强导演权究竟有多强

允许主动注入三类新因：

1. **外生冲击**：疫情输入、自然灾害、经济供需突变、突发事故等；影响必须按地区、传播/物流/资源机制结算。
2. **历史机会**：外交会议、知识交流、暗中赞助、组织宣传、战争借口、政治阴谋机会；事件为已有行为提供新可能，而不是代替当事人完成行动。
3. **有意识的相遇安排**：主动建立聚会与介绍路径，甚至支付组织者资源和让某人有参加理由；最终仍可能失约、拒绝、死亡或因战争改道。

每个 Director Proposal 带 `scope`、`effective_date`、`causal_inputs`、`novelty_or_reversion_goal`、`resource/strength_budget`、`probable_affected_population`、`provenance`。校验通过并提交后才是世界事实。Director 可以偏向某种著名历史场面，但其偏好不能成为绕过死亡、行程和资源的特权。

## 11. 内容工厂示例：不是生成 100 条“失业了”日志

**战时难民家庭内容族**应包含真实参与者：逃亡家庭、原居地政府/军队、边境管理、交通网络、收容社区、学校、雇主、医院、失散亲属。可执行行为：申请证件、雇佣交通、被阻拦、求亲友担保、加入救济、亲属搜寻；后果：资产损失、健康风险、收入变化、分离与重逢、当地劳动力/政治氛围改变。每项都绑定当时真实法律与移动条件。

LLM 可自动生成若干版本：不同国家、战争规模、家庭阶层、亲属条件等，但必须通过规则编译器确认角色能匹配、资源真的流转、结果回到现有社会机制。编译失败是**机制缺口**或内容缺陷，不应强行降低成一条漂亮日志。

## 12. 防止“明明写出系统了，游戏还是垃圾”的可解释性输出

每个具名人物的重大经历至少能回答五个具体问题：

- **发生了什么**（带时间/地点、真实参与者、实际动作、客观后果）；
- **为什么轮到这个人**（匹配到的学校、工厂、关系、家庭、军役/所在地点，不是“随机事件”）；
- **他当时想做什么**（目标、真实请求、认知、反应）；
- **其他人怎么回应**（谁有权说了算、拒绝/合作、利益冲突）；
- **后来变成了什么**（持续事务、关系、职位、法律、组织和未来事件资格的改变）。

这不是强制为所有小事写五段解释，而是引擎的因果记录必须能支持这样的追问。否则我们无法证明所谓“人生与历史相互影响”真实存在。
